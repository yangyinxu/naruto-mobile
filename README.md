# 火影手游玩家反馈调查工具

一个本机采集、Luna AI 分析的 B站《火影忍者手游》玩家反馈调查工具。用户通过中文网页创建调查，工具收集公开意见并完整保存在本地，再使用 `gpt-6-luna` 筛选强洞察、判断主题态度并生成可追溯的 Markdown 报告。本地规则仅用于虚构演示和离线流程验证。

## 小白使用

第一次使用和以后启动都可以双击：

```text
启动火影玩家反馈工具.cmd
```

脚本会在需要时自动安装依赖、构建网页并打开浏览器。网页版默认地址是 `http://127.0.0.1:3765`，仅当前电脑可以访问。工具已经运行时再次双击启动脚本，会直接打开现有网页，不会重复启动服务或报端口占用错误。

真实调查会连接用户日常使用、已经登录 B站的 Chrome。网页会自动发现 Chrome 的本地调试端口、请求浏览器授权并检查 B站登录状态；用户不需要填写 `9222`、输入账号或复制 Cookie。远程调试开关和每次连接的 Chrome 授权提示仍需用户本人确认，工具不会绕过浏览器的安全设置。

真实调查由 Archtree 私人服务器代为调用 OpenAI。朋友使用她自己的普通 Archtree 账号登录即可使用；密码不会保存，可轮换的登录会话由 Windows 安全存储加密保存，`OPENAI_API_KEY` 只存在于服务器。评论分析请求只发送视频语境、评论正文、父评论正文和公开互动数，不发送用户名、UID、用户主页或作者哈希。

第一次使用：

1. 保持普通 Chrome 窗口和 B站登录状态开启。
2. 在工具中点击“开启并连接 Chrome”，按图文提示打开 `chrome://inspect/#remote-debugging` 的远程调试开关。
3. 返回工具点击“连接并检查 B站”，然后在 Chrome 弹窗中点击“允许”。
4. 工具显示账号已连接后即可开始真实调查。

Chrome 连接只监听当前电脑的 `127.0.0.1`。不同电脑会在运行时自动发现各自的动态端口，既不需要相同端口，也不会访问另一台电脑的 Chrome。要求 Chrome 144 或更新版本。

默认调查：

- 实际采集 5 分钟，暂停时间不计入
- 调查最近 30 天发布的内容
- 关键词默认自动添加“火影手游”前缀，只需填写主题；可关闭开关按原词搜索，开始前可查看实际搜索词；点击“保存关键词”会记住关键词和前缀开关，下次打开自动恢复
- 默认使用 4 个专用调查标签页，可在主页选择 4 或 8 个并行标签页
- AI 初筛和详析共享最多 12 个请求的独立并发额度；限流时遵守等待时间并自动降低并发。初筛结果逐批进入详析，每批尽量填满 10 条，各条保留自己的来源与父评论语境
- 分析页分开显示总体处理、Decisions 初筛和 Luna 详析，并列出缓存、本地排除、初筛跳过及详析的合计关系；原始收集数与去重后的处理数分别说明
- 优先热门视频和最新专栏；只保留发布时间确认在内容范围内的来源
- 覆盖多个独立来源后再深入评论
- 单文件 EXE 的数据目录默认为 Windows“文档/火影手游玩家反馈调查工具/data”，源码启动时默认为项目下的 `data/`；两者都可在主页通过系统文件夹选择器更改
- 原始 JSONL 以 UTF-8 明文保存，不做整文件加密；公开用户名、UID 与评论同记录保存，便于逐条溯源
- 首次启动会在数据目录创建随机盐，只用于额外生成兼容旧版本的去重键，不替代明文作者字段

选择新位置后，工具会立即切换到该目录并记住选择，但不会移动原目录中的历史文件。高级用户仍可复制 `.env.example` 为 `.env`，通过 `RESEARCH_DATA_DIR` 固定数据目录；启用该配置时，网页中的位置选择会被禁用。

## 主要能力

- 本地 React 网页 UI 与本地原始数据，无数据库
- Playwright 通过本机 Chrome DevTools Protocol 读取 B站公开可见页面并继承现有登录状态
- 自动读取 Chrome 的 `DevToolsActivePort`，不写死或向用户暴露调试端口
- 主页可选择 4 或 8 个专用并行标签页；标签页越多，采集更快，但电脑负载和平台限流风险也更高
- 真实调查使用 Luna AI；虚构演示使用本地规则
- 采集时长与内容发布时间范围分别配置，可自定义 1–720 分钟
- 原始 JSONL 只追加，派生数据可以重新生成
- 每条新记录带调查 ID；评论同时保存公开用户名、UID、平台评论 ID、父评论 ID、来源页/直达链接和采集时间
- 原子检查点与运行锁，支持安全暂停和跨进程恢复
- Luna 分析中断或应用关闭后可点击“继续分析并生成报告”，复用已保存的分析缓存，不需要重新连接 Chrome 或增加采集时间
- Transient Node and Chrome fetch failures, including interrupted response bodies, retry up to six attempts per batch with exponential backoff. Persistent detail failures preserve completed cache records for explicit resume; cancellation, account changes, and unrelated programming errors do not trigger transport retries.
- 提前终止后直接清洗，并通过 Luna 结构化筛选后生成报告
- 全量原始数据保存在本地；本地只剔除可确定的纯表情、纯数字等硬噪声
- Decisions API（gpt-6-luna）按意见 ID 分别提问，做“详细分析 / 不确定 / 明确跳过”高召回初筛；仅跳过置信度与类别概率均达到 0.85 的非产品反馈，低置信度、拒答、格式异常或请求失败均进入 gpt-6-luna medium 详细分析
- 报告分别显示 Decisions 初筛和 Luna 详析的调用数与预估费用；详析按普通输入、缓存读取、缓存写入和输出分别计费
- AI 将各来源的意见填入完整批次，每条保留独立语境；限速并发、按服务端提示退避重试并缓存最终结果，可恢复处理数千条意见
- AI 输出强洞察、弱信号、无价值内容、主题级态度、行为意图和逐字证据
- 分析时实时显示初筛、详析、在途意见数、响应等待时间和重试倒计时；完成数按已保存结果更新
- 创作者标题与观众评论分开分析
- 多主题、主题级情绪、行为意图和证据门槛
- 网页报告、单文件 HTML / Markdown 导出和本地文件夹入口
- 历史调查可直接浏览完整意见/来源记录，支持用户名、UID、评论 ID、正文和视频搜索，并可展开原始 JSON
- 历史调查支持导出单次调查 ZIP，以及导入别人分享的调查；原始记录、分析结果、缓存和已有报告一起保存

## 导出可离线阅读的 HTML 报告

在报告页面点击“导出 HTML”，保存一个 `.html` 文件。CSS 样式、交互脚本、全部主题和各类情绪的完整证据都内嵌在文件中，无需另带 CSS、JavaScript 文件，也不依赖网络、EXE、Node.js 或本地服务。公司电脑可直接用 Chrome 或 Edge 打开该文件，并切换主题、查看正向 / 混合 / 负向 / 中性意见。

报告包含样本判断、数据质量、AI 用量和费用、来源链接与样本限制。原文链接需要联网访问；报告本身可离线阅读。如果浏览器禁用 JavaScript，会按顺序展示全部主题与意见。“打印 / 保存 PDF”会打印全部主题和全部情绪证据，当前未选中的内容也会包含。HTML 使用经典报告样式。

“导出 Markdown”保留文本报告导出。HTML 用于阅读已生成的报告；需要继续调查、重新分析或浏览完整原始记录时，请使用调查 ZIP 导入功能。

## 分享与导入调查

在“历史调查”中，点击某条记录的“导出调查”，保存一个 ZIP 压缩包后即可发给别人。正在采集或分析的调查需先暂停或等到完成。

收到压缩包的人打开本工具，在“历史调查”点击“导入调查”并选择 ZIP。已有报告可直接查看，完整记录也可搜索浏览，不需要登录 Archtree、连接 Chrome 或重新运行分析。导入会创建独立的本地记录，保留原调查日期；同一份压缩包再次导入也不会覆盖已有调查。

支持本工具导出的 ZIP，也支持将单个调查目录整体压缩得到的 ZIP。每个包仅包含一次调查，ZIP 文件大小上限为 128 MiB（约 134 MB）。调查包只包含该次调查的数据，不包含应用账号、登录会话或本机配置。

## 数据和合规边界

- 只采样公开可见页面，不处理验证码，不绕过登录或访问限制。
- 工具只新建和关闭自己的调查标签页，不导航或关闭用户原有标签页；调查期间 Chrome 授权能够访问整个浏览器配置文件，建议先关闭网银、邮箱等敏感页面。
- 公开用户名、公开 UID 和评论正文会以明文保存在本地，用于把分析结果追溯到原始公开来源；工具不采集 IP 属地等页面未用于研究的额外画像字段。
- 数据目录包含可识别的公开账号信息，使用者应限制目录访问，不要把 `data/runs/` 提交到 Git 或无意分享给他人。
- 热门优先样本不代表全体玩家，报告必须展示来源覆盖和样本限制。
- 真实模式会把去标识化的评论分析语境经 `https://kashewt.com/naruto-mobile/api/v1` 发送给私人 Archtree 服务器，再由服务器调用 OpenAI；本地原始 JSONL 不会上传为文件。
- 打包后的 EXE 主动忽略本机 `OPENAI_API_KEY`。Archtree 密码不持久化，refresh session 使用 Electron `safeStorage`/Windows DPAPI 加密保存，access token 只保留在主进程内存中。
- AI 结果通过稳定意见 ID 和逐字证据回指原始数据，仍应定期使用人工标准答案集评测。
- 规则分类器是演示和回退基线，不用于真实调查结论。
- 演示模式全部为虚构数据，报告会明确标注，不能用于真实判断。
